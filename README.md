# Planejador de Estudos

Um primeiro sistema web em Python para controlar materias, metas e sessoes de estudo.

## O que este projeto ensina

- Criar um servidor web simples com Python.
- Receber dados de formularios HTML.
- Salvar informacoes em um banco SQLite.
- Mostrar um painel com totais e ultimos registros.

## Como rodar

No terminal, dentro desta pasta, execute:

```powershell
python app.py
```

Se o comando `python` ainda nao estiver instalado no seu Windows, use o Python embutido do Codex nesta sessao:

```powershell
& 'C:\Users\fernandafvs\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' app.py
```

Depois acesse:

```text
http://127.0.0.1:8000
```
